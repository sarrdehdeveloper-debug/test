## 2. ما الذي تم بناؤه

### الموقع العام
- الصفحة الرئيسية بهوية الشعار (الذهبي والكحلي)، بالعربية (من اليمين لليسار) والإنجليزية.
- **القراءة المجانية**: تاريخ الميلاد + البريد + اللغة ← يحسب Python البرج الغربي وحيوان السنة الصيني ← يعرض قراءة جاهزة (48 قراءة مكتوبة بالعربية والإنجليزية).
- **التقرير المدفوع**: التاريخ والساعة والدقيقة + البلد والمدينة (بحث بالعربية والإنجليزية بين 69 ألف مدينة، مع اختيار العاصمة تلقائيًا للدول ذات المنطقة الزمنية الواحدة) + البريد + كود الخصم.
  - يحسب الشمس والقمر والطالع، وأعمدة السنة والشهر واليوم والساعة الصينية، ويتعامل مع التوقيت الصيفي.
  - بعد تأكيد الدفع: 6 برومبتات إلى Gemini بفاصل 1–2 ثانية، وإعادة أي رد أقل من 25 كلمة.
  - ملف PDF مصمم (شعار، ترويسة، تذييل، عربي وإنجليزي) باسم عشوائي من 64 حرفًا، يُنزَّل فورًا ويُرسل رابطه بالبريد، والرابط صالح 24 ساعة ثم يُحذف الملف.
- صفحات العروض، والمدونة، ومكتبة المجرّة (Galaxy Library)، والخصوصية، والشروط، والتواصل.

### لوحة التحكم (`/admin`)
- دخول بكلمة مرور ومصادقة ثنائية، وصلاحيات (مالك / مدير / محرر).
- الطلبات، والمهام الفاشلة، والإعدادات (السعر، نموذج Gemini، الفواصل…)، والمستخدمون، وسجل التعديلات.
- **البرومبتات الستة**: تعديل بنسخ، ومعاينة، وتجربة مع الذكاء الاصطناعي، ونشر.
- المحتوى: نصوص الموقع بالعربية والإنجليزية، والقراءات المجانية، والعروض والبانر، والخصومات، والمكتبة، والمدونة، ومكتبة الصور.

### التقنيات
- `backend/`: Python 3.11، FastAPI، SQLAlchemy، PostgreSQL، وطابور مهام داخل PostgreSQL (لا يحتاج Redis أو RabbitMQ).
- `frontend/`: Next.js 16، Tailwind 4، next-intl.
- التفاصيل الكاملة في `docs/ARCHITECTURE.md`.

## 3. أين توقفنا بالضبط

بدأت مرحلة **المراجعة النهائية** (6 مجالات: الأمان، الدفع، الحسابات الفلكية، الواجهة، تغطية متطلبات العميل، النشر).
انقطعت بسبب الوصول إلى حدّ الاستخدام:
- ✅ اكتملت مراجعة **الأمان** و**الدفع** و**المتطلبات**: ظهرت 29 ملاحظة، محفوظة في `docs/REVIEW-FINDINGS.md`.
- ❌ لم تُنجز مرحلة **التحقق** من هذه الملاحظات، ولم تبدأ مراجعة **الحسابات الفلكية** و**الواجهة** و**النشر**.
- ✅ أصلحتُ فورًا ملاحظة واحدة خطيرة (SEC-05): كان ملف كوكيز تجريبي لجلسة المدير محفوظًا في المستودع. حذفته، وأضفت قاعدة في `.gitignore` تمنع تكراره، وألغيت كل جلسات قاعدة البيانات التجريبية.

### أهم الملاحظات التي يجب إصلاحها أولًا (حسب الخطورة)
1. **SEC-01**: المحرر يستطيع رؤية أكواد الخصم الخاصة بالمدير عبر ربطها بعرض.
2. **PAY-01**: استرداد دفعة مكررة يلغي تقرير العميل رغم أن دفعته الأصلية صحيحة.
3. **PAY-02**: تعطل Gemini أو البريد لأكثر من دقيقة يُفشل الطلب نهائيًا دون تنبيه.
4. **SEC-02 / PAY-03**: كود خصم لمرة واحدة قد يُستخدم أكثر من مرة إذا أُرسلت طلبات متزامنة.
5. **REQ-02**: يجب منع إعداد البريد «console» في الإنتاج، حتى لا يفشل إرسال التقارير بصمت.
6. **REQ-01**: حذف البيانات بعد 30 يومًا لا يحذف كل ما يدل على وقت الميلاد ومكانه.
7. **PAY-05 / REQ-05**: قبول ردود Gemini المقطوعة.

القائمة الكاملة، مع وصف كل ملاحظة وطريقة إصلاحها، في `docs/REVIEW-FINDINGS.md`.

   - مفتاح Gemini API وحساب Stripe (أو مزوّد دفع آخر).

   - اعتماد طريقة حساب السنة الصينية (Lichun أم رأس السنة القمرية).
   - مراجعة نصوص الخصوصية والشروط قانونيًا.
   - مراجعة النصوص العربية من محرر.

## 6. تشغيل المشروع على جهازك

الطريقة الأسهل (تحتاج Docker):
```bash
git clone <رابط المستودع> && cd test
git checkout claude/read-project-h0o06e
docker compose up --build
# الموقع: http://localhost:3000   ·   لوحة التحكم: http://localhost:3000/admin
docker compose exec api python -m app.cli create-admin --email you@example.com --password 'كلمة-مرور-طويلة'
```
بدون Docker: الخطوات في `README.md`.
بالإعدادات الافتراضية يعمل كل شيء دون اتصال: دفع تجريبي، ونص تجريبي بدل Gemini، والبريد يُحفظ في `backend/storage/outbox/`.

### الاختبارات
```bash
cd backend && . .venv/bin/activate && python -m pytest
cd frontend && npm run lint && npx tsc --noEmit && npx vitest run && npm run build
```
